# ScopeShield

**Protect your scope. Preserve your client relationships.**

ScopeShield analyzes client requests against a signed contract. A self-hosted Gemma model proposes typed atomic asks; a Mastra workflow orchestrates the analysis; strict Zod schemas validate it; and deterministic TypeScript verifies every citation and scope rule before a response is drafted.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

The default `mock` mode is deterministic and requires no API credentials. Select a contract, paste a client request, and analyze it at `http://localhost:3000`.

## Inference

Set `INFERENCE_MODE=openai-compatible`, `INFERENCE_API_KEY`, `INFERENCE_BASE_URL`, and `INFERENCE_MODEL` in `.env.local` to connect the OpenAI SDK to an authenticated vLLM/OpenAI-compatible endpoint hosting Google Gemma 4. The model response must be JSON matching the schema in [`lib/schemas.ts`](./lib/schemas.ts); malformed output is rejected.

## Verification guarantees

- Quotes are normalized only for whitespace and case, then checked as exact substrings of the cited canonical clause.
- Missing clauses, invalid quotes, and unverifiable claims always produce `AMBIGUOUS`.
- Verdicts and response drafts are generated by trusted TypeScript from verified facts, never from free-form model prose.
- MVP revision tracking is represented in each result's revision number; no database is required.

## Deployment

Deploy the Next.js app as a Render Web Service with `npm install`, `npm run build`, and `npm start`. Keep inference credentials in Render environment variables only. Run vLLM on a DigitalOcean GPU Droplet behind HTTPS, require an API key, expose only the `/v1` endpoint, and set its model name in `INFERENCE_MODEL`. Do not expose the GPU host directly to the public internet.
